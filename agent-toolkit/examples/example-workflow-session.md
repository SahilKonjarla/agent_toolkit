# Example Workflow Session: Deliver Feature

1. User asks to deliver a feature.
2. Architect reads `agent-toolkit/workflows/deliver-feature.md` and relevant context.
3. Architect drafts `feature-specification.md` and `model-execution-plan.md` in memory or as proposed artifacts.
4. Human approves specification and write/implementation scope.
5. Application Engineer implements scoped changes and writes an implementation report.
6. Human approves handoff to review.
7. Quality Engineer reviews, separates confirmed defects from risks/suggestions/nits, and produces a review report.
8. Human approves any remediation.
9. Relevant engineer remediates.
10. Quality Engineer verifies and final report is produced.
